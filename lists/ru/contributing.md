# Правила для участников

Спасибо, что помогаете с этим списком.

- Добавляйте сюда только ресурсы на русском языке.
- Используйте формат `- [Название](https://link) - Описание.`
- Добавляйте запись в конец подходящего раздела.
- Описание короткое и нейтральное, начинается с заглавной буквы, заканчивается точкой и не начинается с названия ресурса.
- Используйте только разделы из [structure.json](../structure.json), в том же порядке и с точным русским названием.
- Не оставляйте пустых разделов. Добавляя первую запись в раздел, добавьте его и в `## Contents`.
- Перед коммитом запустите `npm test`.

Полные правила находятся в [основном руководстве](../../contributing.md).
